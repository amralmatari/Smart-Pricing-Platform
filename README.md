# 💡 منصة تسعير المنتجات الذكية - المحلل التنافسي

## 📌 نبذة عن التطبيق
تطبيق ويب تفاعلي مبني باستخدام إطار العمل `Streamlit` يهدف إلى مساعدة أصحاب الأعمال ومسؤولي التسعير على تحليل أسعار منتجاتهم مقارنة بالمنافسين في السوق. يتيح التطبيق محاكاة وضبط هوامش الربح ونسب التخفيض بشكل تفاعلي وذكي للخروج بأفضل استراتيجية تسعير ممكنة.

---

## ✨ المميزات الرئيسية
- **تحليل المنافسين تلقائياً:** مقارنة أسعار المنتجات مع أسعار المنافسين بشكل تلقائي واحتساب "متوسط السوق".
- **التسعير الذكي:** اقتراح أسعار نهائية للمنتجات بناءً على "نسبة التخفيض المستهدفة" و"الحد الأدنى لهامش الربح".
- **تنبيهات وتوجيهات ذكية:** إبراز المنتجات التي تتطلب مراجعة بشرية (مثل المنتجات التي تم الاستناد فيها إلى منافس واحد فقط، أو تلك التي يقع هامش ربحها تحت الحد الأدنى المطلوب).
- **التحليل البصري (Data Visualization):** رسومات بيانية تفاعلية وأنيقة (باستخدام `Plotly`) لمقارنة الأسعار، وفهم وضعية المنتجات في السوق بشكل سريع.
- **واجهة مستخدم عربية بالكامل (RTL):** دعم أصيل وممتاز للغة العربية مع تصميم عصري يعتمد على البطاقات (Cards) ولوحات التحكم.
- **تصدير التقارير:** إمكانية تصدير التقرير النهائي الشامل كملف Excel، أو استخراج تقرير تحليلي مفصل بصيغة HTML/PDF لكل منتج على حدة.

---

## 🛠️ طريقة الاستخدام
1. **تحميل القالب الجاهز:** من خلال تبويب "البيانات" في القائمة الجانبية، قم بتحميل قالب الإكسل القياسي.
2. **إعداد البيانات:** قم بتعبئة القالب بأسماء المنتجات، التكلفة، وأسعار المنافسين المتوفرة.
3. **الاستيراد:** ارفع الملف المكتمل إلى المنصة.
4. **التحكم والتسعير:** من خلال تبويب "التسعير"، حدد الإعدادات الاستراتيجية:
   - نسبة التخفيض عن متوسط السوق (%).
   - الحد الأدنى المسموح به لهامش الربح (%).
5. **التحليل:** راجع الجدول الرئيسي التفاعلي، واضغط على أي منتج لرؤية تقريره المفصل عبر النافذة المنبثقة.
6. **الحفظ والمشاركة:** استخدم أزرار التصدير في الأعلى لتحميل بياناتك المنقحة.

## ⚙️ متطلبات التشغيل (Installation)
التطبيق يعمل بلغة Python ويتطلب تثبيت المكتبات الموضحة في ملف `requirements.txt`:
- `streamlit`
- `pandas`
- `plotly`
- `openpyxl`
- `Jinja2`

**خطوات التشغيل المحلي (Local Deployment):**
```bash
# 1. تثبيت المتطلبات
pip install -r requirements.txt

# 2. تشغيل التطبيق
streamlit run app.py
```
